# PenLink — iPad как графический планшет для Windows (личный проект)

Статус: **v0.2**. Захват на гибридной графике, NVENC и работа с iPad требуют проверки на Windows. FPS и задержка не измерялись.

## Схема
```
Windows: DXGI захват → H.264 (NVENC или FFmpeg/libx264) ─ TCP ─► iPad: AVSampleBufferDisplayLayer (HW-декодер)
Windows: Pointer Injection (перо: нажим, наклон) ◄─ TCP ◄─ iPad: Apple Pencil (coalesced, hover), хоткеи, жесты
Транспорт: USB-кабель через Apple Mobile Device Service (usbmuxd, ставится с iTunes). Запасной — Wi-Fi: penlink-host.exe --ip <IP iPad>
```
iPad слушает порт 47801; хост сам находит iPad по USB и подключается. Брандмауэр для USB не нужен.

## Сборка
**iPad (без Mac):** залить папку в приватный репозиторий GitHub → Actions → Build iPad app (IPA) → скачать `PenLink.ipa` → поставить через Sideloadly (нужен iTunes с apple.com) со своим Apple ID. Профиль живёт 7 дней.

**Хост (Windows):** Visual Studio Build Tools (C++), CMake, FFmpeg BtbN «win64-gpl-shared» с NVENC, D3D11VA и libx264 (например, 8.1 из GitHub Actions) в `C:\ffmpeg`:
```
cmake -S host -B build -DFFMPEG_DIR=C:/ffmpeg
cmake --build build --config Release
copy C:\ffmpeg\bin\*.dll build\Release\
```

## Запуск (каждый раз)
1. Подключить iPad кабелем, разблокировать, нажать «Доверять».
2. Запустить `penlink-host.exe` (опции: `--fps 60`, `--kbps 40000`, `--ip ...` для Wi-Fi).
3. Открыть PenLink на iPad. Хост печатает «iPad подключён», экран появляется на iPad.

Хост выводит список адаптеров и дисплеев DXGI, выбранный источник захвата и кодировщик. Приоритет у основного дисплея. Если экран подключён к Intel или AMD, кадры считываются через системную память и загружаются на NVIDIA для NVENC. Если NVENC недоступен, запускается libx264. Межадаптерное копирование и программное кодирование могут увеличить задержку.

Если захват не запускается, запустите хост из терминала, чтобы увидеть код HRESULT. Проверьте, что дисплей активен и хост работает в интерактивной сессии Windows.

Photoshop/Clip Studio Paint: включить Windows Ink. Если они запущены от администратора, хост тоже запускать от администратора.

## Реализовано
Захват DXGI и кодирование H.264, перо (нажим, наклон, hover, все промежуточные точки), кривая нажима, жесты (2 пальца — сдвиг/масштаб, тап двумя = Undo, тремя = Redo), панель (перетаскивается, сворачивается, хоткеи с удержанием), fps и RTT в панели, переподключение после обрыва кабеля.

## Не сделано / ограничения
- Стримится родное разрешение монитора; режимы 1440p и 120 Гц требуют масштабирования или виртуального дисплея (и монитор 120+ Гц).
- Нет авторизации (при USB риск минимален; для `--ip` по Wi-Fi порт открыт в сети).
- TCP: при перегрузке канала кадры могут запаздывать; битрейт задавайте умеренно (USB 2.0 хватает для 40–100 Мбит/с).
- Нет редактора хоткеев, мультимониторности, HEVC. Ось azimuth может потребовать инверсии.

## Замеры
- Хост печатает `fps=` и «захват→отправка, мс» раз в секунду; iPad показывает приёмный fps и RTT.
- Полную задержку «перо → линия» снимайте iPhone в slo-mo 240 fps: считайте кадры между движением пера и появлением линии.
